# Historical design material

Documents in this directory preserve earlier design explorations and decisions. They may describe unimplemented infrastructure or superseded behavior; they are not the current runtime specification.

Use the [system design](../system_design.md) for implemented versus proposed features, [architecture](../architecture.md) for current components, [technical reference](../technical_reference.md) for configuration/storage, and [roadmap](../enterprise_roadmap.md) for release gates. Preserve these historical files for context rather than treating their claims as current verification evidence.
